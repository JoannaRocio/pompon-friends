# Política de privacidad — Pompon Friends

_Última actualización: 18 de octubre de 2026_

## Español

**Pompon Friends** es un juego de mascotas virtuales que funciona sin conexión. Esta política explica qué información usa el juego.

**Qué datos recopilamos:** el juego no pide registro, no tiene cuentas, no pide email y no recopila datos de ubicación, de dispositivo ni de uso.

**Dónde se guarda tu partida:** en la memoria de tu propio dispositivo (progreso, monedas, ropa, muebles, configuración de sonido). Si desinstalas el juego o borras sus datos, esa información se elimina de ese dispositivo.

**Guardar en la nube (opcional):** solo si tocas "Guardar en la nube", una copia de la partida se envía a nuestro servidor (servicio Supabase) para que puedas recuperarla en otro dispositivo. La copia incluye el progreso del juego, el nombre que escribiste al empezar y el nombre de tu Pompon. No incluye email, teléfono, ubicación ni datos del dispositivo. Cada partida se identifica solo con un código al azar que te muestra el juego (por ejemplo ABCD-EFGH-JKLM); quien tenga ese código puede recuperar la partida, así que guárdalo en un lugar seguro. Desde ese momento la copia se actualiza sola mientras juegas. Para borrarla, escríbenos al contacto de abajo con tu código.

**Amigos (opcional):** solo si tocas "Activar amigos", el juego recibe un código de amigo (por ejemplo K7F3-QW2M) y publica en nuestro servidor una "tarjeta" con tu Pompon (aspecto, nombre y ropa), su habitación y el nombre que escribiste al empezar. Esa tarjeta la ven solo los jugadores que aceptaste como amigos y a quienes les mandas una solicitud. Para ser amigos, uno manda una solicitud con el código del otro y el otro tiene que aceptarla. No hay chat ni mensajes escritos entre jugadores: solo avisos armados por el juego ("vino a visitarte", "te dejó un regalo"). Puedes quitar a un amigo en cualquier momento. Para borrar tu tarjeta del servidor, escríbenos con tu código de amigo.

**Copia de seguridad de Android:** si tu dispositivo Android tiene activada la copia de seguridad, el sistema puede guardar los datos del juego en tu cuenta de Google y restaurarlos al reinstalarlo. Esto lo hace Android, no el juego, y se controla desde los ajustes del dispositivo.

**Anuncios y terceros:** el juego no muestra anuncios, no usa herramientas de analítica ni de seguimiento, y no incluye SDK de terceros que recopilen datos.

**Niños:** el juego es apto para todo público. No pedimos datos de contacto de nadie. El único dato personal que puede salir del dispositivo es el nombre que se escribe al empezar, y solo si se usa "Guardar en la nube" o "Amigos"; recomendamos usar un apodo y compartir el código de amigo solo con personas conocidas.

**Cambios en esta política:** si en el futuro se agregan funciones que usen datos (por ejemplo compras dentro de la aplicación o visitas entre jugadores), se actualizará esta política y se indicará en la ficha de la tienda antes de publicar el cambio.

## English

**Pompon Friends** is an offline virtual-pet game. This policy explains what information the game uses.

**Data we collect:** the game has no sign-up or accounts, does not ask for an email, and does not collect location, device or usage data.

**Where your progress is stored:** in your own device's storage (progress, coins, clothes, furniture, sound settings). Uninstalling the game or clearing its data deletes it from that device.

**Cloud save (optional):** only if you tap "Guardar en la nube" (save to the cloud), a copy of your game is sent to our server (Supabase service) so you can restore it on another device. The copy includes game progress, the name you typed when starting and your Pompon's name. It does not include email, phone, location or device data. Each save is identified only by a random code shown in the game (for example ABCD-EFGH-JKLM); anyone with that code can restore the save, so keep it somewhere safe. From then on the copy updates automatically while you play. To delete it, write to the contact below with your code.

**Friends (optional):** only if you tap "Activar amigos" (turn on friends), the game gets a friend code (for example K7F3-QW2M) and publishes on our server a "card" with your Pompon (look, name and clothes), its room and the name you typed when starting. That card is seen only by players you accepted as friends and by those you send a request to. To become friends, one player sends a request with the other's code and the other has to accept it. There is no chat or written messages between players: only notices made by the game ("came to visit you", "left you a gift"). You can remove a friend at any time. To delete your card from the server, write to us with your friend code.

**Android backup:** if your Android device has backup turned on, the system may store the game's data in your Google account and restore it when you reinstall. This is done by Android, not by the game, and is controlled from the device settings.

**Ads and third parties:** the game shows no ads, uses no analytics or tracking tools, and includes no third-party SDKs that collect data.

**Children:** the game is suitable for everyone. We never ask anyone for contact details. The only personal data that can leave the device is the name typed when starting, and only if cloud save or friends are used; we recommend using a nickname and sharing the friend code only with people you know.

**Changes to this policy:** if features that use data are added in the future (for example in-app purchases or visiting other players), this policy will be updated and the store listing will say so before the change is published.
