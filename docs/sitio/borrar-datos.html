Borrar tus datos de Pompon Friends

Español · English

Pompon Friends no tiene cuentas ni pide email. Todo se guarda en tu celular, salvo si usaste Guardar en la nube o Amigos. Con esta página pides que borremos lo que está en nuestro servidor.

Cómo pedir el borrado

  1. Abre el juego y anota tus códigos:
    • Código de la nube (12 letras y números, por ejemplo ABCD-EFGH-JKLM): en el menú, botón de la nube.
    • Código de amigo (8 letras y números, por ejemplo K7F3-QW2M): en Vecinos, "Tu código de amigo".
  2. Completa lo de abajo y toca Pedir el borrado. Se abre un correo ya escrito: solo tienes que enviarlo.
  3. Lo borramos dentro de los 30 días y te respondemos para avisarte.

Si ya no tienes el juego o no encuentras los códigos, escríbenos igual a jrsakugawa@gmail.com contando qué quieres borrar.

No guardamos copias de lo que borramos. Si alguien te denunció, esa denuncia se puede conservar hasta que la revisemos (como mucho 90 días) para cuidar a los demás jugadores.

Para madres, padres y adultos

Un adulto puede pedir el borrado de los datos de un chico con este mismo formulario. No hace falta ningún otro dato: con el código alcanza. Más información en la política de privacidad.

Pompon Friends has no accounts and never asks for an email. Everything stays on your phone, unless you used Save to the cloud or Friends. Use this page to ask us to delete what is on our server.

How to request deletion

  1. Open the game and write down your codes:
    • Cloud code (12 letters and numbers, for example ABCD-EFGH-JKLM): in the menu, cloud button.
    • Friend code (8 letters and numbers, for example K7F3-QW2M): in Neighbors, "Your friend code".
  2. Fill in the form below and tap Request deletion. A ready-made email opens: just send it.
  3. We delete it within 30 days and reply to let you know.

If you no longer have the game or can't find the codes, write to jrsakugawa@gmail.com anyway and tell us what you want deleted.

For parents and adults

A parent can request deletion of a child's data with this same form. No other information is needed: the code is enough. More in the privacy policy.
